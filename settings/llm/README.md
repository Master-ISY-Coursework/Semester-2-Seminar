# Local models

Requires Ollama running. From the repository root:

```bash
python3 scripts/start-models.py
```

- API: `http://127.0.0.1:11434/v1`
- Model names: `seminar-answer` and `seminar-judge`
- API key if required: `ollama`

Edit `models.json` and rerun to change models. API names stay the same.
